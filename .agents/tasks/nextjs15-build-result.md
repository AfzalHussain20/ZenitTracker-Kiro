## Remaining Peer Dependency Warnings

`@opennextjs/cloudflare@1.20.9` requires `next >= 15.5.27`, which is now satisfied exactly.
`npm install --legacy-peer-deps` was used locally. The Cloudflare Pages build command should include `--legacy-peer-deps` (e.g. `NPM_FLAGS=--legacy-peer-deps` environment variable) to avoid ERESOLVE errors in CI.
